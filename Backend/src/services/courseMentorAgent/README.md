# პირადი დამხმარე მენტორი (Personal Assistant Mentor)

კოდში ტექნიკური სახელია `courseMentor` / `course-mentor`.

უნივერსალური აგენტი, რომელიც მასწავლებლის ატვირთულ სასწავლო მასალას (სამინისტროს
სახელმძღვანელოები, PDF/DOCX/MD/TXT) კურსად აქცევს: ალაგებს თემებს, ანაწილებს
სასწავლო დღეებზე და (მე-2 ეტაპიდან) თვითონ ასწავლის სტუდენტებს.

## ეტაპები

| ეტაპი | რას აკეთებს | სტატუსი |
|---|---|---|
| 1 | მასალის ატვირთვა → კურსის ავტომატური გეგმა (მოდულები, თარიღიანი გაკვეთილები), მასწავლებლის რედაქტირება და დამტკიცება | ✅ ეს ფაილები |
| 2 | სტუდენტის გაკვეთილი: ახსნა მაგალითებით, შეკითხვები, სავარჯიშოები, ტესტი, საშინაო დავალება პლატფორმაზე | ✅ `enrollmentService`, `lessonRunner`, `taskService` |
| 3 | შეფასება, რეპორტი მასწავლებლისთვის (ნამუშევრები თანდართული), ანალიტიკა, ტემპის კონტროლი | შემდეგი |
| 4 | კოდის უსაფრთხო გაშვება (C/Java/JS) ავტომატური შემოწმებისთვის | სურვილისამებრ |

## როგორ მუშაობს (1-ლი ეტაპი)

1. **ატვირთვა** (`documentIngestion.ts`): ფაილი → ტექსტი (`ai/documentParserService.ts`) →
   გვერდების ნომრების გასუფთავება → ძველი ქართული შრიფტის (AcadNusx) გასწორება
   (`legacyGeorgianFont.ts`) → სათაურებიანი ნაწილები და სარჩევი (`textProcessing.ts`) →
   embeddings (`embeddings.ts`, თუ ჩართულია).
2. **დაგეგმვა** (`curriculumPlanner.ts`):
   - AI „არქიტექტორი“ კითხულობს ყველა დოკუმენტის სარჩევს და ადგენს მოდულებს სწავლების რიგით;
   - `calendar.ts` ითვლის სასწავლო დღეებს (კვირის დღეები, არდადეგები) და ანაწილებს მოდულებზე წონის მიხედვით — ზუსტად, AI-ს გარეშე;
   - AI „გაკვეთილების დიზაინერი“ თითო მოდულისთვის (8-8 გაკვეთილად) პოულობს საჭირო ადგილებს წიგნში (`retrieval.ts`) და გეგმავს ზუსტად იმდენ გაკვეთილს, რამდენი დღეც ეკუთვნის.
3. **მასწავლებელი** ათვალიერებს გეგმას, ასწორებს გაკვეთილებს და ამტკიცებს (`courseService.ts`).

prompt-ების ტექსტი ცალკეა: `prompts/plannerPrompts.ts`. ატვირთული დოკუმენტების ტექსტი
prompt-ში ყოველთვის `<source>` ბლოკშია და მონაცემად ითვლება (prompt-injection დაცვა).

## AI და Azure

- ტექსტი: `ai/aiAgentService.callTextModel` — Azure OpenAI (ძირითადი → სარეზერვო რეგიონი) → Gemini.
- ძიება: `AZURE_OPENAI_EMBEDDING_DEPLOYMENT` (მაგ. `text-embedding-3-small`) — **არასავალდებულო**.
  თუ არ არის დაყენებული, ძიება keyword-ით (BM25) მუშაობს; დაყენების შემდეგ ახლად ატვირთული
  დოკუმენტები ავტომატურად მიიღებენ ვექტორებს.
- ფაილები: Azure Blob (`private-media`, საქაღალდე `course-mentor/<courseId>`).

## API

`routes/courseMentor.ts` → `/api/course-mentor/...` (ცალკე ხელსაწყო, გასაღები `course-mentor`: ადმინი, AccessGrant, მოგვიანებით ფასიანი ადგილები).
Frontend: `Frontend/pages/dashboard/tools/course-mentor/`, `Frontend/src/components/tools/courseMentor/`.

## ტესტი ლოკალურად, ბაზის გარეშე

```
cd Backend
npx ts-node --transpile-only scripts/courseMentorDryRun.ts out.json book1.pdf book2.docx
```

აწყობს კურსის სტრუქტურას და პირველი ორი მოდულის პირველ გაკვეთილებს (AI ხარჯი მცირეა).
unit ტესტები: `npx jest src/services/courseMentorAgent`.

## უნივერსალურობა

აგენტი ნებისმიერ საგანზე მუშაობს: სფეროს თვითონ ადგენს მასალიდან და მასწავლებლის აღწერიდან.
დავალებების ტიპები (`taskTypes.ts`): ტესტი, მოკლე პასუხი, ესე, ამოცანა/გამოთვლა, ქეისი, დაკავშირება,
პრაქტიკული აქტივობა, დიზაინი, პროექტი, კოდი, შეცდომის პოვნა. მასწავლებელს შეუძლია შეზღუდოს კურსზე;
ცარიელი = აგენტი საგანს მიხედვით ირჩევს. კოდის ტიპები მხოლოდ პროგრამირების მასალაზე.

## მასალის ფორმატები (`sources/`)

| წყარო | როგორ | ხარჯი |
|---|---|---|
| PDF, DOCX, DOC, RTF, ODT, PPTX, ODP, XLSX, ODS, CSV, TSV, EPUB, TXT, MD, JSON, HTML | ტექსტის ამოღება (`fileExtractors.ts`) | უფასო |
| სკანირებული PDF, ფოტო (PNG/JPG/WEBP) | gpt-4o vision OCR (`ocr.ts`), მაქს. 300 გვერდი | ~0.03 ₾ / გვერდი, ერთჯერადად |
| ვებგვერდის ბმული | უსაფრთხო ჩამოტვირთვა (SSRF დაცვა) + ტექსტი | უფასო |
| Google Docs / Slides / Sheets / Drive | „ყველას ბმულით“ გაზიარებული → export | უფასო |
| YouTube | სუბტიტრები, თუ YouTube იძლევა; ხშირად ბლოკავს (2025-დან token სჭირდება) → „ტექსტის ჩასმა“ | უფასო |
| ჩასმული ტექსტი | პირდაპირ | უფასო |

**არ მუშაობს:** პაროლიანი/დახურული ბმულები, DRM-ით დაცული ელწიგნები, აუდიო/ვიდეო ფაილები ტრანსკრიპტის გარეშე
(აუდიოს ტრანსკრიფცია Azure Speech-ით შესაძლებელია მომავალში, ~1 ₾ / საათი).

## ხარჯი და ფასი

ფასი: **19 ₾ / სტუდენტი / თვე**, პირადი სწავლა 19 ₾ / თვე (`config/courseMentorPricing.ts`).
ჩატი gpt-4o-mini-ზე, გადართვა gpt-4o-ზე როცა სტუდენტი ვერ ხვდება / რთული შეკითხვაა (დღეში მაქს. 6).
შეფასება, დავალების შემოწმება, გეგმა — gpt-4o. დღიური ლიმიტები: `usageLimits.ts`.
სავარაუდო ხარჯი სტუდენტზე თვეში: ჩვეულებრივ ~9 ₾, მაქსიმუმ ~14 ₾.
